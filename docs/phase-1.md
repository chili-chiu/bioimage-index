# Phase 1

What we are building, and what you will be able to review. Phase 1 runs 2026–2027.

## Deliverables

| Deliverable | What it is | License (proposed) |
|---|---|---|
| **Core Schema v0** | An image-level schema, openly licensed and reusable beyond this project. | MIT preferred |
| **Metadata Exchange Protocol** | How a repository exposes its image-level records so an index can use them. | MIT preferred |
| **Resource onboarding** | Extracting image-level metadata from the five founding resources and mapping it to the core schema. | n/a |
| **Search API and portal (proof of concept)** | Cross-resource, image-level search that anyone can try. | Apache-2.0 preferred |
| **Governance and repository certification** | How repositories join, and what "ready to be indexed" means. | CC BY 4.0 (governance documents) |

!!! info "About licenses"
    Licenses shown are the current proposal and are being confirmed with partners. Image-level metadata is proposed under CC0, and each record keeps the license named by its repository of origin.

## Out of scope for Phase 1

Full metadata harmonization, consolidated storage, and automated harvesting. These are deliberate boundaries, not oversights.

## Success criteria for moving to Phase 2

- Image-level data from all five founding resources
- Core Schema v0 published as an openly licensed resource
- A cross-resource search API and portal that anyone can try
- Governance, sustainability planning and production-readiness criteria in place
