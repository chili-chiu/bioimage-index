# Get involved

Whether you search for images, run a repository, or build tools, we want to hear from you. The earlier we hear what you need, the easier it is to build it in.

## How to reach us

- **GitHub Issues:** open an issue in the [bioimage-index repository](https://github.com/chili-chiu/bioimage-index/issues). Issues are our place for open discussion, so others can follow along and add their own experience.
- **Email:** write to [CONTACT EMAIL] if you prefer a private conversation first.

## Researchers and data users

Tell us what you would want to search for and what is hard today. Real questions shape the schema and the portal.

Useful things to share:

- A search you would like to run across repositories
- What a result must show before you would trust it, such as license, modality, resolution or access
- What you wish repositories exposed that they do not today

## Repositories and data resources

Run a public bioimage repository? Tell us how you describe images today, so the schema works beyond the founding five. Phase 1 onboards five resources, and broader onboarding comes later.

Useful things to share:

- How your metadata is structured and where it is exposed
- The image formats you hold, including any OME-Zarr
- What would make your resource easy to index

## Standards and tool builders

Working on OME-Zarr, RO-Crate, search or metadata tooling? We would love to hear from you:

- Standards and conventions you think the index should build on
- Tools that could use image-level search results
- Overlap with your own work that we should know about
