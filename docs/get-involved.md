# Get involved

Follow along, push back, or join in. The earlier we hear from you, the cheaper it is to change course.

## Researchers and data users

Tell us what you would want to search for and what is hard today. Real questions shape the schema and the portal.

## Repositories and data resources

Run a public bioimage repository? Follow along and compare how you describe images today, so the schema works beyond the founding five. Phase 1 onboards five resources; broader onboarding comes later.

## Standards and tool builders

Working on OME-Zarr, RO-Crate, search or metadata tooling? Review drafts as they appear, open issues, and tell us where we should align rather than invent. [Follow on GitHub](https://github.com/bioimage-index){ .md-button }
