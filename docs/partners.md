# Partners and governance

Seven founding partners, one shared plan.

- Allen Institute
- Biohub
- EMBL-EBI · BioImage Archive
- University of Dundee · Image Data Resource (IDR)
- RIKEN · SSBD
- German BioImaging (GerBI)
- openRxiv

## How the work is organized

In Phase 1, Biohub provides project management, communications and milestone tracking. Each founding partner owns specific deliverables and onboards its own repository. An Interim Steering Council meets every two months, and working groups lead each deliverable.

Governance is drafted in the open in the [governance repository](https://github.com/bioimage-index/governance).
