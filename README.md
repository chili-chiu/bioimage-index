# BioImage Index

**Does this public bioimage exist, and where is it?**

BioImage Index is a federated, image-level search layer for public bioimaging data. Repositories keep their data. The index helps people find which images exist and where to get them.

**Project site: https://chili-chiu.github.io/bioimage-index/**

> **Status:** early stage, Phase 1. We are building in the open and looking for use cases and repositories to help shape the schema and protocol.

## Get involved

- **Researchers and data users:** Get involved by telling us what you would want to search for. 
- **Repositories and data resources:** follow along and compare how you describe image data today.

Not sure where to start? [Open an issue](https://github.com/chili-chiu/bioimage-index/issues) with your use case or question.

### Preview locally

The site is built with [Zensical](https://zensical.org/).

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install zensical
zensical serve
```

Then open the address it prints (usually `http://localhost:8000`).
