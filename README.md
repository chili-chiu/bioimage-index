# BioImage Index site

Built with [Zensical](https://zensical.org/).

## Local preview
    pip install zensical
    zensical serve

## Publish
Run `zensical new .` once in this folder to generate the official `.github/workflows/docs.yml` (it will not overwrite existing files),
then set Settings > Pages > Source to "GitHub Actions" and push to `main`.
